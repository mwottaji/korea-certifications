# 한국 국가자격 819종 — 분야별 목록 · 시험 일정 확인처

국가자격(국가기술자격 · 국가전문자격)을 24개 분야로 나누고, 시험 일정을 확인하는 공식 누리집과 종목별 정리 쪽 링크를 한곳에 모은 목록이에요.

- 국가자격 819종(국가기술자격 540 · 국가전문자격 279 — 큐넷과 시행기관 · 법령에서 모은 목록, 2026년 11월 11일 기준)
- 종목마다 시험 일정 · 응시료 · 합격률 · 따는 길은 [뭐따지](https://mwottaji.co.kr) 쪽에 정리돼 있어요
- 시험 일정은 해마다 바뀌어요 — 원서 접수 전에 아래 [시험 일정 확인처](#시험-일정-확인처)에서 꼭 다시 확인하세요
